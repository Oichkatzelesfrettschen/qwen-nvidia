
In exec_hsaout_check the verification of the executable is performed in this sequence: the header is checked with hsx_headers, the packed layout is validated with aout_layout_check, the process context is locked with exec_text_hold, and the first stream of data is loaded using hsx_load_buf. After those steps the second stream of data is loaded (the text and data buffers). If that second expansion does not match the header, the code discards the buffer buffer, releases the text buffer with exec_text_unhold, and then terminates the process with psignal, leaving the process with its original text reference and the exclusion in place.

The `sendsig` function prepares a signal frame to be used by the signal handler. It places this signal frame just below the current stack pointer (`sfp`), which is the stack pointer at the time the signal handler was called. This is done to ensure that when the signal handler executes `sigreturn`, it can correctly restore the stack to its original state before the signal was handled.

The signal frame is placed just below the stack pointer because the stack is used to hold the context of the interrupted process. When a signal is handled, the context (including the stack pointer) is saved so that the process can continue as if it had not been interrupted. The `sigreturn` function uses this saved context to restore the stack to its original state.

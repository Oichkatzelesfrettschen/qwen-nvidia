## Summary

This file implements a USB CDC-ACM (Console) device driver for the Raspberry Pi Pico (RP2040). It provides a serial console over the USB interface, allowing picotool to reboot the board without a physical button press. The driver uses a ring buffer to preserve boot messages when the host is present but slow, and supports the Microsoft OS 2.0 reset interface for compatibility with picotool.

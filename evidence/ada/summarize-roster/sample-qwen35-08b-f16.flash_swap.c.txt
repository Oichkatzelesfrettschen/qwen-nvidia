### 1. What it does overall
This file is a C program designed for a specific device (RP2040) that handles flash memory operations. It manages the erasing and writing of data to a swap image. It is designed to be separate from the flash driver to allow testing against a NOR model that rejects certain bit transitions, unaligned calls, and overlapping images.

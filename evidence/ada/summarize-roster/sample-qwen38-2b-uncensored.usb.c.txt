## Overview

This file is a **USB-to-serial driver** for the RP2040 microcontroller. It implements a **CDC-ACM (Class-Device-ACM)** interface, meaning the RP2040 exposes a USB device that Linux (and other OSes) can bind to as `/dev/ttyACM0` — essentially giving the RP2040 a serial console port.

The driver uses the RP2040's built-in USB controller (a CDC-ACM device) rather than a separate UART peripheral, and it provides a "Reset" interface that lets `picotool` reboot the board without needing a physical button.
